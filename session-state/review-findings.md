## 已處理（2026-07-28 第一版功能完成）

- **寫入失敗回饋** → sheet 內就地顯示 `存不進去：<訊息>`，已選與份量不清空，按鈕換「重試」。實測過失敗與重試成功兩條路徑。
- **記錄流程的返回成本** → 走同頁 sheet 覆蓋層，關閉不重載、不重打 API。
- **食品庫為空／搜尋無結果** → 零結果顯示「找不到『X』」＋新增入口；食品庫全空時清單直接指路到搜尋框新增。
- **0 kcal 食物與「沒存到」無法區分** → 加入成功後新品項套 `--accent-soft` 高亮再淡出，確認訊號不依賴數字變化。
- **「刪除當天某筆」零入口** → 今日頁品項左滑（CSS `scroll-snap`）或點擊都會露出刪除鈕，開一列自動關其他列。
- **已記錄餐次無法追加** → 餐別標題列本身是 `button`，點了開該餐別的 sheet。
- **記錄成功沒有確認訊號** → 同上高亮（只動 `opacity`，`prefers-reduced-motion` 降到 0.01ms）。
