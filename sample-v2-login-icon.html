二、Wordmark 字體（版式定案 W3，這輪比字體本身）

四個變體都是同一套 W3 基線鎖定版式（icon 縮放到跟文字大寫高度同一比例、底部對齊同一條基線、 間距 --s-2）——差別只在 .wm3-text 用什麼字體。F0 是系統字 700 的現況 control； F1–F3 是自架 subset（Google Fonts css2 API 取 text=Tally 專屬子集，base64 內嵌， 不外連）。跟 icon 在 60px／180px 兩個尺寸下並排比較。

四、登入頁極簡化（第五輪：文案與 mark 怎麼搭）

第四輪已裁決：極簡方向成立、CTA 沉到底部拇指區、 wordmark 不出現在登入頁（落點題＝不放、品牌只靠 icon，字體題連帶作廢）。 L2「mark＋一行文案」方向被接受，但被評「那行字跟 logo 搭不起來、有點怪」——診斷：文字被排成了 logo 的 caption（小、灰、貼太近），看起來像圖示的說明標籤，不是頁面在說話。 這輪比三種修法；P3 是「乾脆拿掉」的對照組。

P1 · 拉開距離＋升級成正文
文字從 caption 升級成正文：字級 --t-base → --t-md（16px）、色 --ink-muted → --ink、 與 mark 的間距 16 → 24px。mark 與文字各自成立，一個是圖、一個是話。

P3 · 拿掉文案（對照組）
中心只有 T mark，底部只有 CTA——如果 P1/P2 都還是覺得怪，答案就是這行字 本來就不屬於這一屏。代價：文案定案「今天吃了什麼？」從登入頁退場。
