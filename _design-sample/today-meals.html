今日頁餐別區：三個方向＋「加進來」動效（使用者 2026-11-15）

情境照使用者說的：午餐、點心記了，早餐、晚餐沒記而且有建議（上次／常吃）。現在的問題：同一區四種長相（沒記的餐名、虛線建議框、已記的餐名＋小計、品項列），間距不一，最搶眼的是「還沒記的建議」的填色加入鈕。 三個方向都把建議降成安靜的一行、「加入」改成描邊鈕，主角留給記下來的東西。每支手機的「加入」可以按，看「加進來」：鈕縮成勾 → 建議那行展開成品項（一筆筆落下）→ 小計從 0 滾上去、卡片閃一下。上面的天空與插圖不變，這裡只畫一塊色帶示意。

A　每餐一張卡四餐同一個殼

  • 井然的來源：每餐都是同一張白卡、同一條標題列（餐名＋類型圖示＋右邊小計或「還沒記」），間距只有一種（卡與卡 12px）。
  • 建議：在沒記的那張卡裡，標題下一行淡字＋描邊「加入」，不再有虛線框凸出邊界。
  • 代價：四張卡比現在的清單多佔約 40px 高；第一屏看得到的餐少一點。

B　時間軸一條細線串起四餐

  • 井然的來源：左邊一條細線、四個節點（記了＝實心打勾、沒記＝空心），跟插圖的踏腳石同一套說法；四餐對齊同一條線，不用卡片。
  • 建議：沒記的那餐，節點旁邊一行淡字＋描邊「加入」。
  • 代價：v2.122 拿掉了時間軸的圓點與虛實線（改由插圖說哪幾餐記了），這裡等於把它請回來、跟插圖說兩次。最省高度。

C　已記／還沒記分區兩種東西不混在一起

  • 井然的來源：記了的餐照時間排在上面（白卡）；沒記的收進底下一張虛線卡「還沒記」，每餐一列＋建議＋加入。兩種長相各自成區。
  • 加進來：那一列從「還沒記」收掉，那一餐出現在上面它該在的時間位置。
  • 代價：畫面上的順序不再是早→午→晚→點心（早餐在午餐下面），要靠插圖與餐名對時間。
