今日頁決策樣張 v2

實機測試後三處回饋的具體選項：日期區太小、左滑刪除鈕不好看、關閉另一列時沒有過場。 每組變體有編號，挑好後告訴我編號即可定案，我會回寫 DESIGN.md 與實作。

第一組・日期區

拿掉原生 input type="date"，只留左右箭頭；日期文字放大且可點回今天； 右箭頭在「今天」停用。三個變體各示範「今天」與「歷史日」兩種狀態，點日期文字可切換體驗。

第二組・左滑刪除（覆蓋式）

列本身不動，刪除鈕從右邊滑進來蓋在熱量數字上。仍是 CSS scroll-snap， 無 touch 事件 JS；滑鼠拖曳或觸控都能操作（本機用滑鼠：直接在品項上左右拖曳）。 點品項內容一樣會露出刪除鈕（鍵盤路徑）。三個刪除鈕視覺變體只用 --over-fill / --over。
